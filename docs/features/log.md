## 2026-10-05

- **Updated**: [Auth API](/auth-api.md) and [Auth Foundation](/auth-foundation.md) — recorded that public self-registration is deliberately disabled (only the one-time `POST /setup` and the future operator CLI create users) and corrected the stale "signup" wording; added an e2e regression spec (`apps/api/test/e2e/no-registration.e2e-spec.ts`) asserting that `POST /auth/register` and similar paths return `404` and create no user.
- **Updated**: [First-run Setup](/first-run-setup.md) and [Auth API](/auth-api.md) — the atomic first-user insert is now retried up to `MAX_SETUP_ATTEMPTS` times with a `hasAnyUser()` re-check after each failure, so a losing concurrent `POST /setup` is guaranteed `409` even when the winner's row is not yet visible; a genuine error with no user created is still rethrown. Corrected the stale "(web integration, ticket 2.3)" reference in the Auth API out-of-scope list to ticket 2.5, and added a `forbidNonWhitelisted` unknown-field e2e case.
- **Added**: [First-run Setup](/first-run-setup.md) — `GET /setup/status` (is the `users` table empty?) and `POST /setup` (create the very first account), both `@Public()`; a single atomic `INSERT … SELECT … WHERE NOT EXISTS` plus a post-failure re-check guarantees exactly one winner under concurrency (losers get `409 Setup has already been completed`); shares `UsersService.prepareUser()` with the CLI creation path and logs one info line on success.
- **Added**: [Auth API](/auth-api.md) — `POST /auth/login` (sets the `gameshelf_session` httpOnly/Lax cookie), `POST /auth/logout` (server-side revoke + clear), `GET /auth/me`, a single global `SessionGuard` with `@Public()` opt-outs, the `SESSION_COOKIE_SECURE` config knob, and one generic 401 for bad credentials with a dummy-hash timing equalizer.
- **Added**: [Auth Foundation](/auth-foundation.md) — Argon2id password hashing (`PasswordService`), a MySQL-backed server-side session store whose `sessions.id` holds the HMAC-SHA256 digest of the cookie token (`SessionsService`), finite sliding expiry validated from `SESSION_TTL_MINUTES` (no "never"), an hourly expired-row sweep (`SessionCleanupService`), and env-only configuration (`SESSION_SECRET`). No JWT.
- **Added**: [Import Jobs API](/import-jobs-api.md) — `GET/PATCH /import-jobs`: persisted import runs (status + recognized/imported/unrecognized/declared counts, newest first), per-job flagged-item review (`raw_title` trace, non-dismissed review queue vs full trace), idempotent dismissal of needs-attention/failed jobs and flagged items (sticky, 409 matrix), the pipeline surface (`createJob`/`markProcessing`/`markCompleted`/`markFailed`/`addUnrecognizedItem`) with server-side `done` vs `needs_attention` per spec §4.2.4, and the indefinite retention policy (no TTL, no DELETE).
- **Added**: [Platforms API](/platforms-api.md) — platform CRUD (`GET`/`POST`/`PATCH`/`DELETE` `/platforms`) with per-platform game counts (single `groupBy` aggregate, no N+1), 409 on duplicate name and on delete while games reference the platform, stable slugs across renames, and the canonical IGDB platform list loaded as a seed data-migration generated by the `db:platforms:fetch` script (initial seed pending IGDB credentials).
- **Added**: [Catalog API](/catalog-api.md) — `GET /games` contract: AND-combined filters, case-insensitive partial title search (`q`), deterministic sorting with `id` tiebreaker, filtered pagination totals, available filter values, and filter-column indexes.
