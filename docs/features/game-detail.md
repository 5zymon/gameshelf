# Overview

Ticket 5.4 adds the game detail route at `/games/[id]` behind the authenticated
`(app)` shell (the [Web Auth UI](web-auth-ui.md) session guard), and links every
[Catalog Grid](catalog-grid.md) tile to it. The page is a **server component**
that reads the id from the route, fetches the [Catalog API](catalog-api.md)
`GET /games/:id` record and the `GET /platforms` list in parallel, and renders a
presentational `GameDetailView`. Every mutation runs from a small `'use client'`
control that calls the [Web API Client](web-api-client.md) and then
`router.refresh()`, so the surrounding server-rendered view re-fetches without a
hard reload.

The detail view exists to close the loop opened by import/manual add: a user can
see exactly what was stored, fix a field, delete a mistake, or re-run enrichment
against a corrected title and read the outcome.

# Out of scope

- Editing `copyCount` (no longer shown), the cover, `source` or `enrichedAt`; an "add another copy" action (the API endpoint exists but is not surfaced here).
- Rendering the archival `rawMetadata`: it is still stored and returned by `GET /games/:id` but no longer shown in the UI.
- A frontend test runner.
- i18n (ticket 7.2), platform management (ticket 7.1).
- Any backend or `packages/contracts` change — the endpoints already existed.

# Manual acceptance

1. Open a catalog tile: it navigates to `/games/<id>` and shows the back link, cover, title, platform · edition · year, and the provenance chip row.
2. The record list shows Platform, Edition, Release year, Publisher, Genre, Rating, Source, Added and Updated; empty fields read "Not set". Copies, External ID, Record ID, Platform ID and Players are not listed.
3. The right column shows an **About** / **Media** tab set (PL: **O grze** / **Multimedia**), with **About** selected on load and the edit/re-enrich/delete controls above it. Keyboard: Tab lands on the selected tab, ←/→ move between tabs and wrap, Home/End jump to the first/last tab, and Tab again moves into the panel. A game with no playable video and no same-origin image shows no tab set at all.
4. **Edit record** → change the publisher → **Save changes**: "Saved." appears and the record row updates without a full page reload. Return to `/`: the tile reflects the new title (if changed). Editing while **Media** is selected keeps **Media** selected after the refresh.
5. Clearing an optional field to blank and saving sends `null` (the row returns to "Not set").
6. A field edited here shows the "hand-edited" marker afterwards; a later re-enrich does not overwrite it.
7. **Delete game** → **Delete game**? shows the inline confirmation; **Cancel** (focused) or Escape closes it; **Delete** removes the game and returns to `/`.
8. **Re-enrich from title** with a corrected title: a radio group of ranked candidate cards appears (title/year/publisher/genre/players/platforms/same-origin cover), top match preselected; pick any card and **Apply metadata** reports "Fresh metadata applied." (or "Already up to date — nothing changed.") and the record updates in place. An unresolved title reports "No match found for … Nothing changed."
9. A game with a description shows a "Description" section in the **About** tab (with a "hand-edited" marker after an edit); a rated game shows the `78/100` badge on its grid tile and a "Rating" row on the detail page; a game with videos shows a "Videos" player in the **Media** tab that loads nothing from YouTube until **Play** is pressed. Starting a video and switching to About stops its audio.
10. Every cover request (tile, detail, candidate preview) is same-origin; no CSP violation appears in the Console.
11. `/games/abc` and `/games/999999` render the 404 page; `/games/new` renders the manual-add form ([Manual Add Form](manual-add-form.md)).
